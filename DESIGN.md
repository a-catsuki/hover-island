# Hover Island interface

An understated graphite control surface attached to the top of the desktop. Dark surfaces preserve the notch silhouette and keep attention on the user's active window. Template accents are reserved for actions and state; existing color presets remain available.

The current direction adds personal atmosphere within a 96% opaque shell: pointer-reactive Aurora, Album art, Ember, or Still. Speaker-output energy can drive the light while open; reduced motion freezes it. Today, Desk and Activity are visible tabs with configurable names and direct widget rearrangement. Three size presets replace numeric sizing. The month calendar and remaining allowance are visible information, not decorative placeholders. Hardware transitions use a smaller 340x84 expansion.

- Use Inter Variable with the Windows system font as fallback. Body 13px, secondary 12px, headings 18px, media title 24px. Use tabular figures for timers and usage.
- Separate navigation, content and footer with hairline dividers. Avoid a card around every section.
- Maintain a fixed toolbar, scrollable content and visible navigation at small window sizes.
- Use 16px Lucide icons and 32px action targets; pair labels with unfamiliar actions.
- Keep native bounds fixed during hover. Independent interruptible springs drive the clip's width, height and radius between the compact pill, temporary peek and workspace. Content changes use a short crossfade. Stop hidden speaker visualizers; never request microphone input.
- Use deeper blacks, red calendar dates, an ochre analog/digital clock, blue weather, warm notes and green focus. Each widget has an identifiable purpose and color, with restrained ambient light within the shell.
- Events replace stale bursts, expire once, and preserve a user-owned panel. A hover, focus or pin adopts a temporary peek. File drops open and reveal the bucket without changing its custom placement.
- Buttons, inputs, status text and errors share one vocabulary. Disabled providers show why; failure messages offer a retry.
