# Hover Island

## Register

product

## Users
Windows users who want quick access to music, apps, weather, calendar, notes and AI activity without leaving their current work. The island lives at the top of an everyday desktop, where a bright, busy panel would compete with the active application. Genuine iPhone AirDrop is a requested integration and must never be represented by a different protocol or an unverified capability.

## Product Purpose
A small, dependable desktop companion with a glanceable collapsed state and useful controls on hover or keyboard activation. Rust and the system WebView remain the runtime architecture; responsiveness and modest resource use take priority.

## Brand Personality
Quiet, precise, familiar. The session references Atoll and NotchNook for compact notch interactions, media controls and customization.

## Anti-references
Oversized glowing orbs as the primary interface, decorative card grids, cryptic icon-only controls, clipped controls, repeated permission prompts, silent failures and analytics presented as subscription limits.

## Design Principles
- Make the common action immediately available, with context beside it.
- Keep native and visible state synchronized across hover, shortcuts and tray actions.
- Tell users what a provider actually reports and when it was last updated.
- Make errors recoverable and preferences persistent.
- Let appearance settings change the actual interface while respecting reduced motion.

## Accessibility & Inclusion
Use labeled controls, keyboard navigation, visible focus, readable contrast and reduced-motion support. Hover is an enhancement; clicking and keyboard shortcuts must also work. These are baseline implementation requirements, not a claim of formal conformance.
